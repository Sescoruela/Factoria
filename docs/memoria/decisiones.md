# Decisiones

- La memoria de cada proyecto vive en su propio repositorio.
- `AGENTS.md` debe ser corto y actuar como índice, no como enciclopedia.
- Los proyectos `active` mantienen memoria profunda; los `maintenance` usan una ficha compacta.
- La clasificación se basa en actividad Git reciente y se propone antes de guardarse.
- La ventana de actividad inicial es de 30 días.
- El envejecimiento de memoria se mide por commits y cada documento puede tener su propio umbral.
- `memory-update` revisará la memoria completa y requerirá aprobación antes de escribir cambios.
- La memoria nunca debe contener secretos, credenciales ni datos personales sensibles.
